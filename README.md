Título do projeto: Agendamento de voluntários.
Descrição: Auxiliar na elaboração de escala de vonluntários de uma igreja.
Problema: Encaixar todos os voluntários levando em consideração restrições de dias, turnos e salas.
Solução: O Sistema de mostra de forma clara onde há vagas e que de forma pode encaixar outros voluntários te dando susgestões com a IA integrada a o sistema.
Tecnologias utilizadas:Node.js, React, Fastify, API Gemini.
Como executar o projeto: yarn dev(Front), yarn run dev(Back)
